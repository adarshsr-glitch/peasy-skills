# docs/

Stakeholder-facing artifacts that explain the project but are not part of the skill or pack code.

- `peasy-roadmap.html` — one-page landscape roadmap illustration (Peasy design language, 7 stops across the lifecycle).
- `peasy-roadmap.pdf` — print export of the same, A3 landscape, one page.
- `preview.png` — thumbnail preview of the roadmap.

The roadmap is the stakeholder view of what this project is doing. The plan that drives execution lives at `~/.claude/plans/see-a-thing-that-cozy-lerdorf.md` and the acceptance material lives under `../eval/`.
