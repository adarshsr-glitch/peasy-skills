# pack/examples/

Known-good outputs the skills pattern-match on. Populated after the first scored benchmark passes.

Expected shape, once filled:

- `briefs/<slug>/vague.md` — the original two-line brief
- `briefs/<slug>/enriched.md` — the questionnaire the brainstorm skill filled
- `briefs/<slug>/spec.md` — the Jira-ready document the requirements skill emitted
- `briefs/<slug>/deviations.md` — the design skill's deviations log

Each example here is a reference the skills can look at to decide "a brief like this produces a spec like that." Nothing to add until Phase 3 produces its first clean benchmark output.
