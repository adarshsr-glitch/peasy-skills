# ANB-1293 — Electricity Product Specifications

Jira epic: https://verzekeringen.atlassian.net/browse/ANB-1293
Status: Done
Scope: Admin screen for managing electricity products per supplier within the New Engine Admin.

Every rule below cites the specific child ticket it comes from. The design and requirements skills must preserve these citations in generated output. If a claim here has no citation, it is a bug and the file should be fixed, not the generated output.

## Entity model

An **electricity product** belongs to exactly one **supplier**. The product has 17 specification fields plus system metadata (Product ID, Supplier ID, Created on, Last updated).

## Surface states

The Specifications page has three progressive-disclosure states. See `eval/benchmarks/anb-1293-electricity.md` for the full visibility matrix.

- `no-supplier` — only the supplier dropdown is visible. `[ANB-1307 AC1]`
- `supplier-selected` — supplier dropdown + product dropdown + "Nieuw product" action. `[ANB-1307 AC2]`
- `product-selected` — all of the above + metadata (Product ID, Supplier ID, Created on, Last updated) + 17 spec fields + Save actions + Duplicate action. `[ANB-1307 AC3]`

No placeholder message is shown in the empty state. `[ANB-1307 Notes]`

## Specification fields

The 17 fields, in display order. Options and defaults live in Figma, not in this file.

1. Productnaam NL — text, required, unique per supplier (case-insensitive)
2. Productnaam FR — text, required, unique per supplier (case-insensitive)
3. Status — enum: Actief / Niet actief
4. Toon in vergelijking — enum: Ja / Nee (locked to Nee when Status = Niet actief)
5. Tarieftype
6. Metertype
7. Commissie
8. Online contract
9. Klantendienst
10. Situatie
11. Klantsegment
12. Betaalmethoden
13. Groene energie
14. Regio
15. Contractduur — numeric only
16. Indexeringsperiode — numeric only
17. Verwerkingslink NL / FR — text pair

All 17 are mandatory. `[ANB-1304 AC1, ANB-1304 AC4]`

## Status and visibility rules

- Status = `Actief` → badge green. `[ANB-1306 AC2]`
- Status = `Niet actief` → badge light grey. `[ANB-1306 AC2]`
- Status = `Niet actief` → `Toon in vergelijking` auto-set to `Nee` AND the radio locks (cannot be edited). `[ANB-1306 AC5]`
- Product dropdown items are colored by product status. `[ANB-1306 AC3]`
- Updating Status reflects immediately in the badge after save. `[ANB-1306 AC4]`

## Uniqueness

- Product name must be unique within a supplier, case-insensitive. `[ANB-1358 AC1]`
- The same product name may exist across different suppliers. `[ANB-1358 Notes]`
- Uniqueness is checked on create, duplicate, and save. `[ANB-1358 AC2]`
- Uniqueness applies regardless of Status. `[ANB-1358 Notes]`

## Create flow

- Entry: supplier is selected (product may or may not be), admin clicks "Nieuw product". `[ANB-1303 AC1]`
- Supplier is read-only during creation. `[ANB-1303 AC3]`
- All 17 fields must be filled. `[ANB-1303 AC4]`
- Validation blocks creation if any field is empty, highlights the fields, and shows the required-field message. `[ANB-1303 AC5]`
- After successful creation: new product is auto-selected, metadata displays, Save and Duplicate actions become available, dropdown selectors re-enable. `[ANB-1303 AC6]`
- Cancel ("Annuleren") returns to prior state with no save. `[ANB-1303 AC7]`
- Refreshing during creation = Cancel. `[ANB-1303 Notes]`

## Duplicate flow

- Entry: a product is selected, admin clicks "Dupliceer product". `[ANB-1347 AC1]`
- Prefilled from source: every field EXCEPT Productnaam NL (empty), Productnaam FR (empty), Toon in vergelijking (Nee). `[ANB-1347 AC3]`
- Supplier is read-only during duplication. `[ANB-1347 AC4]`
- Validation and uniqueness apply the same as Create. `[ANB-1347 AC6, ANB-1358 AC2]`
- After successful duplication: new product auto-selected, metadata displays, Save and Duplicate re-enable. `[ANB-1347 AC7]`
- Cancel returns to prior state. `[ANB-1347 AC8]`
- Refreshing during duplication = Cancel. `[ANB-1347 Notes]`

## Save flow

- Save actions appear at both the top and bottom of the page; both perform the same operation. `[ANB-1305 AC1, ANB-1305 Design & Details]`
- Save updates only the currently selected product. `[ANB-1305 AC4]`
- Save updates `Last updated`. `[ANB-1305 AC6]`
- Validation blocks save if any field is empty. `[ANB-1305 AC5]`
- Saved values are persisted and reload correctly. `[ANB-1305 AC3]`

## Supplier binding

- Product dropdown lists only products belonging to the selected supplier. `[ANB-1298 AC2]`
- Supplier must be available in the system — dependency on ANB-1045 Supplier screen epic. `[ANB-1293 Dependencies]`
- Supplier dropdown label is "Leverancier". `[ANB-1298 AC1]`
- Product dropdown label is "Product". `[ANB-1298 AC2]`
