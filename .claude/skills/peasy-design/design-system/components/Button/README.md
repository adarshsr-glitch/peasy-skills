Primary button: the one main action on a screen or card. Sizes L 56, M 48, S 40 px high; forms Full (purple `secondary-500`, white label) and Outline (2px `stroke` border on light, white border on dark). Optional ArrowRight before or after the label (`iconFront`, `iconBack`).

**Use:** one Full button per view or card; Outline for secondary actions next to it. Labels: verb + outcome, 1–3 words ("Bespaar nu", "Kies dit pack").

**Consumer supplies:** label text, `size`, `form`, `surface`, `href` or `onClick`.

**States:** Figma draws only default. Hover (`secondary-600`), focus ring (2px `primary-500`) and disabled are proposals to confirm.
